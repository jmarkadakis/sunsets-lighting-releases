# Sunsets & Soundwaves Lighting: downloads

Lights, visuals and projection mapping for the Mac. Get the newest version here: **[Latest release](https://github.com/jmarkadakis/sunsets-lighting-releases/releases/latest)**

- **Apple Silicon** (M1 or newer): the file ending in **Apple-Silicon.dmg**
- **Intel Macs**: the file ending in **Intel.dmg**
- Not sure? Apple menu → About This Mac. "Chip: Apple M…" means Apple Silicon.
- The .zip files are for in-app updates; you can ignore them.

Open the .dmg and drag the app to Applications. The first time, macOS blocks it: open System Settings → Privacy & Security and click **Open Anyway**. After that the app opens normally and updates itself.
