# Sunsets & Soundwaves Lighting — downloads

DMX lighting control for the Mac. Get the newest version under **Releases** (right side):

- Apple Silicon (M1–M4): the file with **arm64** in its name
- Intel Macs: the one without

Open the .dmg, drag the app to Applications, then the first time right-click it and choose **Open**.
After that the app updates itself.
